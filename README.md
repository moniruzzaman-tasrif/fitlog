# FitLog — Workout Library & Daily Planner

**FitLog** is a dark, modern, no-nonsense fitness web application built with **Next.js**, **React**, and **Tailwind CSS**. It serves as a gym companion allowing users to explore a curated library of workouts, manage saved exercises, and build a targeted daily fitness routine.

---

## Features

- **Comprehensive Workout Library**: Browse major lifts categorized by muscle groups, complete with duration, calorie burn estimates, and user ratings.
- **Interactive Daily Plan ("My Plan")**: Select exercises to add to your daily schedule, track total workout minutes and expected calorie burn.
- **Saved Exercises Management**: Bookmark your favorite lifts for quick access, with options to view details or remove them instantly.
- **Responsive Design**: Fully optimized for mobile, tablet, and desktop devices with a sleek, dark-themed UI.
- **Live Deployment**: Hosted and deployed via Vercel.

---

## Tech Stack

- **Framework**: [Next.js](https://nextjs.org/) (App Router)
- **Library**: React
- **Styling**: Tailwind CSS & DaisyUI
- **Icons**: React Icons
- **Deployment**: Vercel & GitHub Pages
